易错点2：列表是可变参数，比如：
nums=[1,5,8,6,9]  
    a=nums   #实际上并不是把nums的列表传递给a,而是把列表名改为a和nums
    a.pop()      #删除列表对应索引的元素，默认最后一个
    b = nums.copy() #复制列表给b，复制后修改b不会影响原列表，不复制采用上面方法的话修改会同时影响a与nums列表
    b.pop(0)  #删除索引为0的对应元素
    nums.append(11) #添加元素int类型的11到nums列表里面，append只能添加一个元素
    nums+="8" 
    nums.insert(0, 0)     # 索引 0 插入
    nums.remove(1)        # 按值删（删第一个 1）
    nums.sort()           # 原地排序 ← 返回 None
    new = sorted(nums)    # 返回新列表 ← 不改原列表
     nums.sort(reverse=True) #倒序排序

sort与sorted之间的区别：前者改原列表，后者不改，前者改完为None，后者得到新列表：
如：a = nums.sort() → a 是 None。


 nums+="8" #等于list.extend(x)将x逐元素拆开加进去，[1,2] += "8" 得到 [1,2,'8']；[1,2] += "89" 得到 [1,2,'8','9']，extend批量添加，append单个添加，extend不能批量添加int类型的元素，而append可以
此外，在def xx(num:list=[xxxx])函数中，因为列表是可变参数，与int，float，str类型不一样，所以不能使用默认的可变默认，如列表，元素，因为可变参数在初始化创建的时候会记住上一次传入的值，导致生成的不是默认值，所以正常应该是先num:list=None,然后再函数中再添加元素
